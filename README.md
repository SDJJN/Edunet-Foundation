# Edunet-Foundation Week 1 – Introduction to Machine Learning
1. What is Machine Learning?
   
    Machine Learning provides several models that make predictions based on input data. Over time, as the dataset grows, the efficiency of 
    the model in predicting accurate outcomes improves.
    
    Three Basic Types of Machine Learning:
    Supervised Learning: Uses labeled data for training.
    
    Unsupervised Learning: Identifies patterns in unlabeled data.
    
    Reinforcement Learning: The algorithm learns from feedback (rewards or penalties).

3. What is Supervised Learning?
   
    Supervised Learning uses labeled data, where each input is mapped to an output. The model is trained to extract features from this 
    labeled data to make future predictions.

5. What is Classification and Regression?
   
    For every input, there is a corresponding output, which can be of two types:
    
    Continuous Output: Use Regression
    
    Categorical Output: Use Classification
    
    Classification
    Used when the output is categorical.
    Examples: "Yes" or "No", Male or Female.
    
    Regression
    Used when the output is continuous and has a linear relationship with input variables.
    Example: Weather prediction.
